Add your app icons in this folder with these exact filenames:

- `apple-touch-icon.png` (180x180) for iOS Home Screen
- `icon-192.png` (192x192) for Android/PWA
- `icon-512.png` (512x512) for Android/PWA

Tips:
- Use PNG format.
- Keep key content centered with padding to avoid clipping.
- iOS applies rounded corners automatically.
